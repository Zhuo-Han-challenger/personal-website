# Zhuo Han — Personal website

A minimal, responsive academic website featuring transportation research experience and selected publications.

Website: https://zhuo-han-challenger.github.io/personal-website/

## Update on GitHub

Edit index.html and commit to main. GitHub Pages publishes commits automatically once configured with main as the source branch and / (root) as the source folder.

## Update locally

Edit index.html, then run:

    git add index.html
    git commit -m "Update website"
    git push origin main

## Preview

Open index.html in a browser. No dependencies or build process are required.
